# 2026-08-20

## Scene::batch_load 实现（最终版）
- 位置：`luos/scene/english/load.inl`，声明在 `luos/scene/english/available/function.inl`。
- 签名：`void Scene::batch_load(const rapidjson::Document& json, const std::string& type)`。
- 职责：从已解析的 `Document` 中按 `type` 取分组（顶层对象 key=type），遍历 `{函数名: DLL路径}` 调用已有 `load()`。
- **文件解析由调用方负责**（用户明确要求此职责划分），调用示例：
  ```cpp
  配置文件 cfg; cfg.add("json/main.json", "main");
  场景.batch_load(cfg.get("main"), "scene");
  ```

## 编译要点（Windows）
- rapidjson `FindMember` 不接受 `std::string`，需传 `type.c_str()`。
- **`GetObject` 宏冲突**：Windows `<wingdi.h>` 将 `GetObject` 宏展开为 `GetObjectA`，会破坏 rapidjson 的 `GetObject()` 成员。解决：调用加括号 `(typeIt->value.GetObject)()`。
- `Scene` 类没有 `buffer` 成员（那是 `Json` 类的），IStreamWrapper 无需 buffer 参数。

## 背景
- `load` 单函数加载已存在：`data` (unordered_map<string, function<void()>>)、`private_data` (unordered_map<string, HMODULE>)。
- `luos/json` 类（配置文件/Json）提供 add/get 方法解析配置。
