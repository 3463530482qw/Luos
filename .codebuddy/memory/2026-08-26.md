# 2026-08-26

## luos run::specify_window 实现
- 在 `luos/run/english/window.inl` 实现了 `Run::specify_window(Window&)` 与 `Run::specify_remove_window(Window&)`。
- 依据 `luos/run/english/available/internal/variable.inl`：`private_window` 为 `std::unordered_map<std::string, Window*>`，以 `Window.name`（std::string 成员）为键。
- `specify_window` 做 `private_window[Window.name] = &Window;`；`specify_remove_window` 做 `private_window.erase(Window.name);`。
- Window 类成员参考 `luos/window/english/available/variable.inl`（含 `std::string name{"a window"}`）。
- 注意：`luos/run/中文/可用/函数.inl` 尚无对应的中文包装（如 指定窗口），如需可补充。

## luos run::start 迭代窗口
- 更新 `luos/run/english/start.inl`：主循环中新增用迭代器遍历 `private_window`，对每个保存的窗口调用 `it->second->run()`（在 `private_thread->run()` 之前）。
- 注：单个 `.inl` 文件独立 lint 时 `Run` 报 undeclared 是既有的正常现象（.inl 在 main.hpp 的 namespace 内 include），非改动引入。
